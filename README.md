# 通信応答時間チェッカー（Java）

指定したWebサイトへHTTPリクエストを複数回送り、応答時間やHTTPステータスを確認するコマンドラインツールです。Javaの学習成果として、HTTP通信、繰り返し処理、例外処理、リストによる結果管理、平均値などの集計を扱っています。

## 動作環境

- Java 11 以降（`java.net.http.HttpClient` を使用）
- インターネット接続

## 実行方法

ソースコードがあるフォルダで、次のコマンドを実行してください。

```bash
javac NetworkResponseChecker.java
java NetworkResponseChecker
```

画面の案内に従ってURLと測定回数（1～100回）を入力します。URLの例：`https://www.playstation.com/ja-jp/`

## 表示する情報

- 各リクエストのHTTPステータスと応答時間
- HTTP 2xxの成功回数と成功率
- 接続エラーの回数
- 成功した応答の最短・最長・平均応答時間

## 注意事項・制限

- このツールが測定するのは、指定したWebサイトへのHTTPリクエストの応答時間です。
- 通信速度、動画の再生品質、PlayStation Portalのストリーミング品質を直接測定するものではありません。
- 相手側のサーバー負荷、ネットワーク環境、時間帯などによって結果は変わります。
- 短時間に大量のリクエストを送らず、対象サイトの利用条件を守ってください。
